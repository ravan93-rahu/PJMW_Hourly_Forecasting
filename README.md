# PJMW_Hourly_Forecasting
This project analyzes historical hourly electricity consumption data in MW to identify hourly, daily, seasonal, holiday, and long-term trends. The project uses data preprocessing, feature engineering, and forecasting models to predict energy consumption, with a focus on evaluating performance and generating a 30-day future forecast.
“My project is P679 – Hourly Energy Consumption Forecasting. The project uses historical hourly PJM electricity consumption data measured in megawatts. The main objective is to analyse historical energy-consumption behaviour and build forecasting models that can predict future electricity demand.

First, I performed Exploratory Data Analysis to understand the structure and quality of the data and identify hourly, daily, weekly, monthly, yearly and seasonal patterns. I also analysed how energy consumption changes during different periods of the day and across different seasons.

After EDA, the next stage is preprocessing and feature engineering, where I prepare the time-series data for forecasting by handling data-quality issues and creating time-based, lag and rolling features.

Then I will split the data chronologically, keeping the most recent year as the test period as specified in the project requirement. Multiple forecasting models will be trained and evaluated using appropriate error metrics. Finally, the best-performing model will be used to forecast energy consumption for the next 30 days.”
